Electrochemistry Metadata

The schemas describe electrochemical data: the electrochemical system (electrodes, electrolyte, cell, atmosphere), the experimental setup and instrumentation, the source of the data, its curation, and the description of digitized figures.

  • Schema reference: the available schema types and all their classes, fields and allowed values.

  • Example files: complete example metadata for each schema type and for individual parts.

  • JSON Schema downloads: the generated JSON Schemas, to validate metadata with any JSON Schema tool.
