# Electrochemistry Metadata

The schemas describe electrochemical data: the electrochemical system (electrodes, electrolyte, cell, atmosphere), the experimental setup and instrumentation, the source of the data, its curation, and the description of digitized figures.

- [Schema reference](schemas.md): the available schema types and all their classes, fields and allowed values.
- [Example files](examples.md): complete example metadata for each schema type and for individual parts.
- {ref}`JSON Schema downloads <json-schemas>`: the generated JSON Schemas, to validate metadata with any JSON Schema tool.
